# Party Dungeon

パーティで挑むダンジョンを作って遊べるMOD（Minecraft 1.21.1 / NeoForge）。作成中です。

## .jar の受け取り方
1. GitHub のこのリポジトリで「Actions」タブを開く
2. いちばん上の緑のチェック（✓）がついた実行を開く
3. 下の「Artifacts」にある `party-dungeon-jar` をダウンロード（zip の中に .jar があります）

## 予定している機能
- クリエイティブの作業場でダンジョンを作成（部屋の外枠は自動建築）→ 登録して公開
- 挑戦用の部屋は全ダンジョン共用で使い回し。クリアするとすぐリセット
- 難易度5段階（イージー／ノーマル／ハード／ベリーハード／カオス）
- 難易度ごとの報酬テーブル
- クリア条件はダンジョンごとに選択（ボス撃破／全滅／ゴール到達）
- ダンジョン内のブロックは壊れない（クリーパーOK）
- 入っているMODのモブも全部出せる
- 罠、ランキング

テンプレート部分は NeoForged MDK（MIT、TEMPLATE_LICENSE.txt 参照）を元にしています。
