# Party Dungeon

パーティで挑むダンジョンを作って遊べるMOD（Minecraft 1.21.1 / NeoForge）。

**サーバーとクライアントの両方の `mods` フォルダに入れてください。**

---

## 遊ぶ人向け

| やりたいこと | コマンド |
|---|---|
| ダンジョンを選んで入る | `/pd play`（一覧の画面が開きます。クリックでパーティ全員が入場） |
| 途中で抜ける | `/pd exit` |
| 仲間を誘う | `/pd party invite <名前>` |
| 誘われたら | `/pd party accept`（断るなら `decline`） |
| パーティを抜ける | `/pd party leave` |
| メンバーを外す（リーダー） | `/pd party kick <名前>` |
| メンバーを見る | `/pd party list` |
| 使い方を見る | `/pd help` |

- パーティに入っていなければ、1人で挑戦できます
- ダンジョンを選べるのはリーダーだけです
- ダンジョンの中ではアドベンチャーモードになり、ブロックは壊せません（爆発でも壊れません）
- 死んでも持ち物と経験値はなくならず、スタート地点から再開します
- クリアすると、10秒後に元の場所へ戻ります

## ダンジョンを作る人向け（OP）

### 1. 作業場に行って区画を作る
```
/pd workshop
/pd create "はじまりの洞窟" 48 24
```
- `48` は広さ（16〜128）、`24` は高さ（8〜96）。省略すると 48×48、高さ24
- 最後に壁のブロックも指定できます（例：`/pd create "氷の城" 64 32 minecraft:packed_ice`）
- 床・壁・天井が自動で建ちます。中を自由に建築してください
- 天井を外すと、ゾンビなどが日光で燃えるので注意してください

### 2. 目印を決める（区画の中に立って使う）
| コマンド | 内容 | 目印 |
|---|---|---|
| `/pd setstart` | 立っている場所をスタート地点に | 緑のキラキラ |
| `/pd setgoal [半径]` | 立っている場所をゴールに | 白い光 |
| `/pd spawn add <モブ> [数] [距離] [ボス]` | 立っている場所に敵を置く | 炎（ボスは青い炎） |

敵の置き方の例：
```
/pd spawn add minecraft:zombie 3            ← 開始と同時にゾンビ3体
/pd spawn add minecraft:creeper 2 8         ← 8ブロックまで近づいたらクリーパー2体
/pd spawn add minecraft:wither 1 12 true    ← 12ブロックまで近づいたらボスのウィザー
```
- ほかのMODのモブも選べます（入力中に候補が出ます）
- 置いた敵の確認：`/pd spawn list`、消す：`/pd spawn remove <番号>`、足元の敵を消す：`/pd spawn removenear`

### 3. クリア条件を選ぶ
```
/pd clear all    ← 敵を全部倒す（最初はこれ）
/pd clear boss   ← ボスを全部倒す
/pd clear goal   ← ゴール地点に着く
```

### 4. 公開する
```
/pd info      ← 公開できる状態かチェック
/pd publish   ← 公開！ /pd play の一覧に出ます
```
建物を直したら、もう一度 `/pd publish` すれば反映されます。

### その他
| コマンド | 内容 |
|---|---|
| `/pd list` | 作ったダンジョンの一覧 |
| `/pd goto "名前"` | その区画へ移動 |
| `/pd rename "新しい名前"` | 名前を変える |
| `/pd unpublish` | 非公開にする |
| `/pd rooms` | 部屋の使用状況 |
| `/pd exit` | 作業場から出る（元の場所・ゲームモードに戻ります） |

## 設定（サーバー管理者向け）

`world/serverconfig/partydungeon-server.toml`

| 項目 | 初期値 | 内容 |
|---|---|---|
| `rooms.count` | 5 | 同時に使える部屋の数（全ダンジョン共用） |
| `rooms.maxPerDungeon` | 0 | 1つのダンジョンが同時に使える部屋の上限（0＝なし） |
| `rooms.blocksPerTick` | 20000 | 部屋の組み立て・リセットの速さ。重ければ減らす |
| `party.maxSize` | 5 | パーティの最大人数 |
| `run.returnDelaySeconds` | 10 | クリア後、戻るまでの秒数 |
| `run.keepInventory` | true | ダンジョン内で死んでも持ち物を失わない |

## .jar の受け取り方
1. GitHub のこのリポジトリで「Actions」タブを開く
2. いちばん上の緑のチェック（✓）がついた実行を開く
3. 下の「Artifacts」にある `party-dungeon-jar` をダウンロード（zip の中に .jar があります）
