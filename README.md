# Party Dungeon

パーティで挑むダンジョンを作って遊べるMOD（Minecraft 1.21.1 / NeoForge）。

**サーバーとクライアントの両方の `mods` フォルダに入れてください。**

---

## 画面の開き方
- **受付の村人に話しかける**（OP が `/pd npc` で置けます。`/pd npc 名前` で好きな名前に）
- **P キー**（マイクラの「設定 → 操作設定」で変更できます）
- コマンド `/pd`

## 遊ぶ人向け
1. メイン画面の **「ダンジョンに挑む」** → ダンジョンを選ぶと **ロビー** へ
2. ロビーで **「メンバーを招待」**（オンラインの人の顔から選ぶ）か **「仲間を募集する」**（サーバー全員に知らせる）
3. 誘われた人は、チャットの **[参加する]** を押すか、メイン画面の **「募集中のパーティ」** から参加
4. リーダーが **難易度** を選んで（ロビー上の羊毛のボタン。左クリックで難しく、右クリックでやさしく）
5. **「スタート！」** を押すと、パーティ全員で入場

| 難易度 | 敵の体力 | 敵の攻撃力 | 敵の数 | 移動速度 |
|---|---|---|---|---|
| イージー | ×0.6 | ×0.6 | ×0.75 | ― |
| ノーマル | ×1 | ×1 | ×1 | ― |
| ハード | ×1.6 | ×1.4 | ×1.25 | ― |
| ベリーハード | ×2.5 | ×2 | ×1.5 | +10% |
| カオス | ×4 | ×3 | ×2 | +30% |

クリア報酬は、クリアした人それぞれに抽選され、元の場所に戻ったときに持ち物に入ります（いっぱいなら足元に落ちます）。

- 1人で挑戦することもできます
- ダンジョンの中ではアドベンチャーモードになり、ブロックは壊せません（爆発でも壊れません）
- 死ぬと、そのダンジョンからは抜けて元の場所に戻ります。持ち物と経験値は残ります（**カオスだけは全ロス**）
- クリアすると10秒後に元の場所へ戻ります。途中で抜けるときはメイン画面の「ダンジョンから抜ける」

## OP 向け：ダンジョンの作り方
1. P キー →「製作モードへ」（作業場・クリエイティブに移動。道具が持ち物に入ります）
2. 製作メニューの **「設計スペースへ」** で広い床へ
3. 間取りブロックで床に間取りを描く。**白** が部屋、**灰** が通路、**赤** がスタート地点、**紫** がボス部屋
   - 白は1マスでも部屋（1マスの大きさ×1マスの大きさの四角）になります
   - 灰はとなりのマスとつながる細い通路になります（幅は「通路の幅」）
   - **紫（ボス部屋）** のかたまり → 円形の部屋（天井の高さ 20 固定、明かり多め）
4. **間取りの杖** で間取りを右クリック → 名前・1マスの大きさ（8〜）・通路の幅・高さを入れて［作る］
   - 床・壁・天井・明かりが自動で建ち、スタートブロック（緑）が置かれます
5. 部屋の中に目印ブロックを置いて、**右クリックで設定**
   - **敵の出現ブロック**：モブを検索・MODで絞り込んで選び、数と出る距離を入力。ボスにもできます
   - **ゴールブロック**：範囲を入力（クリア条件が「ゴール」のとき）
   - **報酬チェスト**：難易度ごとの報酬（どこに置いても同じ）
   - 目印ブロックは、挑戦のときは消えます
6. P キー →「製作メニュー」で、クリア条件・公開・**公開してテストプレイ**（難易度も選べます）
7. 終わったら「遊ぶモードに戻る」

間取りを使わず、ただの四角い部屋から作るときは「空の区画を作る」。

同じことはコマンドでもできます（下の表）。

## ダンジョンを作る人向け（OP）

### 1. 作業場に行って区画を作る
```
/pd workshop
/pd create "はじまりの洞窟" 48 24
```
- `48` は広さ（16〜128）、`24` は高さ（8〜96）。省略すると 48×48、高さ24
- 最後に壁のブロックも指定できます（例：`/pd create "氷の城" 64 32 minecraft:packed_ice`）
- 床・壁・天井が自動で建ちます。中を自由に建築してください
- 天井を外すと、ゾンビなどが日光で燃えるので注意してください

### 2. 目印を決める（区画の中に立って使う）
| コマンド | 内容 | 目印 |
|---|---|---|
| `/pd setstart` | 立っている場所をスタート地点に | 緑のキラキラ |
| `/pd setgoal [半径]` | 立っている場所をゴールに | 白い光 |
| `/pd spawn add <モブ> [数] [距離] [ボス]` | 立っている場所に敵を置く | 炎（ボスは青い炎） |

敵の置き方の例：
```
/pd spawn add minecraft:zombie 3            ← 開始と同時にゾンビ3体
/pd spawn add minecraft:creeper 2 8         ← 8ブロックまで近づいたらクリーパー2体
/pd spawn add minecraft:wither 1 12 true    ← 12ブロックまで近づいたらボスのウィザー
```
- ほかのMODのモブも選べます（入力中に候補が出ます）
- 置いた敵の確認：`/pd spawn list`、消す：`/pd spawn remove <番号>`、足元の敵を消す：`/pd spawn removenear`

### 3. クリア条件を選ぶ
```
/pd clear all    ← 敵を全部倒す（最初はこれ）
/pd clear boss   ← ボスを全部倒す
/pd clear goal   ← ゴール地点に着く
```

### 4. 公開する
```
/pd info      ← 公開できる状態かチェック
/pd publish   ← 公開！ /pd play の一覧に出ます
```
建物を直したら、もう一度 `/pd publish` すれば反映されます。

### その他
| コマンド | 内容 |
|---|---|
| `/pd list` | 作ったダンジョンの一覧 |
| `/pd goto "名前"` | その区画へ移動 |
| `/pd rename "新しい名前"` | 名前を変える |
| `/pd unpublish` | 非公開にする |
| `/pd rooms` | 部屋の使用状況 |
| `/pd exit` | 作業場から出る（元の場所・ゲームモードに戻ります） |

## 見た目（フィールド）と罠

### 見た目のテーマ
間取りから作るとき・空の区画を作るときに「見た目」のボタンで選べます。
石レンガの迷宮／洞窟／森の遺跡／砂漠の神殿／氷の城／海底神殿／地底の古代都市／ネザー要塞／エンドの城／闇の砦／木の屋敷／白い宮殿

作ったあとでも、製作メニューの「見た目」→「この見た目に着せ替える」で床・壁・天井・明かり・ボス床をまとめて置き換えられます
（自分で置いた飾りはそのまま）。遊ぶ人に反映するには「もう一度公開」してください。

### 罠（クリエイティブタブ「パーティダンジョン」）
- **矢の発射台**：向いている方向へ矢を撃つ。右クリックで間隔（0.5〜5秒）、スニーク＋右クリックで「前に人が来たら／いつでも」を切り替え（クリエイティブのみ）
- **トゲの床**：乗っているあいだダメージ
- **崩れる床**：乗ると少しして消え、3秒で元に戻る
- **落下リターンブロック**：落とし穴の底に敷く。落ちてくると、落ちる前に立っていた場所へ戻される（ハート半分のダメージ）
- **状態異常の床**：乗っているあいだ効果がかかる
  - 炎・毒・鈍足・弱体化・暗闇・ウィザー・混乱・空腹・浮遊
  - いい床：加速・ジャンプ強化・回復
- クリエイティブの人には効かないので、テストプレイで確かめてください。

## ランキング・順番待ち・再挑戦の待ち時間

- **ランキング**：ダンジョンを選ぶ画面で、ダンジョンにカーソルを合わせると難易度ごとの1位（タイムとメンバー）が見られます。
  右クリックでランキング画面（1位〜5位・メンバー最大5人の顔）。下のボタンで難易度を切り替え。
  同じ顔ぶれの記録は一番速いものだけ残ります。テストプレイは記録されません。`/pd ranking reset <名前>` で消せます。
- **順番待ち**：部屋が全部使われているときにスタートすると順番待ちに並び、空いたら自動で始まります。ロビーの時計ボタンでやめられます。
- **再挑戦の待ち時間**：同じダンジョンは、挑戦が終わってから 10 分たつまで挑めません（設定で変更・0 でなし）。

## まとめて書き出し・読み込み（1人用 ⇔ サーバー）

製作メニューの左下のボタンで、ダンジョン全部と jsn-Craft の依頼（依頼エディターで作った物）を、1つのファイルでやり取りできます。

1. 書き出したいワールド（1人用でもサーバーでも）で **「全部書き出し」** を押す
   → 押した人のパソコンの `partydungeon/exports/` に `.pdb` ファイルが保存されます
2. 読み込みたいワールド・サーバーに入って **「読み込み」** を押し、ファイルを選ぶ
   → ファイルがサーバーへ送られ、確認画面が出ます
3. 1つずつチェックして **「読み込む」**
   - **新しい**：まだない物 → 追加（最初からチェック）
   - **更新**：前に読み込んだ物で、こちらでは変えていない → 上書き（最初からチェック）
   - **同じ**：中身が同じ（チェックなし）
   - **こちらで変更あり！**：こちらで直した物。読み込むと上書きされるので、最初はチェックなし

- 何回でも読み込めます。2回目からは同じ物を上書きするので増えません（ランキングや進み具合は残ります）
- 読み込んだ後も、ふつうに作業場や依頼エディターで直せます。逆向き（サーバー → 1人用）もできます
- 依頼の中のダンジョン（攻略・ダンジョン解放）や「先に達成」は、読み込み先のIDに自動で付け替えます
- 片方で消したダンジョン・依頼は、もう片方からは消えません（手で消してください）
- OP（チート有効）の人だけ使えます

## 1つずつの書き出し・読み込み（コマンド）

- `/pd export <名前>` → サーバーのフォルダの `partydungeon/exports/<名前>.pdd` にできます
  （建物・目印・敵・報酬・クリア条件・解放の設定・公開中の設計図。ランキングは入りません）
- 別のサーバーでは、`partydungeon/import/` に入れて起動すると自動で読み込みます（読み込んだファイルは `import/done/` へ）。
  起動中なら `/pd import <ファイル名>` でも読めます。
- 元のID（d1 など）が空いていればそのままのIDになるので、jsn-Craft の依頼（「攻略」「ダンジョン解放」）もそのままつながります。
  IDが使われていた場合は新しいIDになり、メッセージで知らせます。

## jsn-Craft の依頼とつなぐ（どちらも入っているとき）
- 製作メニューの **「解放: 最初から遊べる／依頼で解放」** で、そのダンジョンを「解放が必要」にできます。
- 解放が必要なダンジョンは、一覧で **[鍵]** つきで表示され、どの依頼で解放できるかが出ます。リーダーが解放していれば、まだの仲間もいっしょに挑めます。
- jsn-Craft の依頼エディターで、
  - 目標 **「攻略」**：ダンジョンを（○○以上の難易度で）クリアする
  - **「ダンジョン解放」**：報酬を受け取ると、そのダンジョンが解放される
  - **「先に達成」**：前の依頼を終えないと受けられない
  を組み合わせると、「Aをクリア → Bが解放 → Bをクリア → Cが解放…」と続けられます。
- jsn-Phone が入っていれば、クリアしたことがスマホのお知らせに流れます。

## 設定（サーバー管理者向け）

`world/serverconfig/partydungeon-server.toml`

| 項目 | 初期値 | 内容 |
|---|---|---|
| `rooms.count` | 15 | 同時に使える部屋の数（全ダンジョン共用、1〜30） |
| `run.retryCooldownMinutes` | 10 | 同じダンジョンにもう一度挑めるまでの待ち時間（分）。0 でなし |
| `rooms.maxPerDungeon` | 0 | 1つのダンジョンが同時に使える部屋の上限（0＝なし） |
| `rooms.blocksPerTick` | 20000 | 部屋の組み立て・リセットの速さ。重ければ減らす |
| `party.maxSize` | 5 | パーティの最大人数 |
| `run.returnDelaySeconds` | 10 | クリア後、戻るまでの秒数 |
| `run.keepInventory` | true | ダンジョン内で死んでも持ち物を失わない |
| `run.chaosLosesItems` | true | カオスで死んだら持ち物と経験値をすべて失う |
